## Описание проекта

Данный исследовательский проект посвящен оценке и математическому моделированию взаимодействия человека с носимыми устройствами (wearable devices) для оценки ментального здоровья. 

Исследование направлено на разработку математических моделей, способных точно оценивать психоэмоциональное состояние и когнитивные показатели на основе анализа паттернов взаимодействия пользователя с устройством, физиологических сигналов и поведенческих метрик, собираемых носимыми сенсорами. Проект объединяет методы систематического обзора литературы, анализ данных и математическое моделирование для создания комплексной методологии мониторинга ментального здоровья.

---

## Цели и задачи исследования

1. Провести систематический обзор существующих подходов и алгоритмов оценки ментального здоровья с использованием носимых устройств.
2. Проанализировать паттерны взаимодействия «человек-компьютер» (HCI) при использовании носимых устройств мониторинга здоровья.
3. Разработать математические модели для количественной оценки состояния ментального здоровья на основе телеметрии и данных о взаимодействии.
4. Выполнить валидацию предложенных моделей с использованием открытых и эмпирических наборов данных.
5. Сформулировать практические рекомендации по оптимизации алгоритмов и интерфейсов носимых устройств для задач ментального здоровья.
